# 📊 Dashboard de Inteligencia de Datos para la Cobertura y Equidad Educativa

## Descripción
Proyecto de Business Intelligence desarrollado en **Power BI** para analizar la cobertura y la equidad educativa en los 135 municipios de la Provincia de Buenos Aires, integrando datos oficiales de establecimientos educativos y del Censo Nacional 2022 (INDEC).

## 🚀 Highlights
- Modelo Estrella (Star Schema)
- Más de 21.600 registros procesados
- ETL en Power Query
- Medidas DAX
- Dashboard georreferenciado
- ArcGIS Maps

## 🛠 Tecnologías
- Power BI Desktop
- DAX
- Power Query
- ArcGIS Maps
- CSV
- INDEC 2022
